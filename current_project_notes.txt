## 1. Implementation Progress
- Added the COMPACT assembly optimization profile: BASIC stack-pair cleanup, removal of JP/JR branches to the immediately following label, conservative flag-aware Z80 substitutions (LD A,0; redundant CP 0; LD A,r / NEG; groups of eight ADD HL,HL; adjacent immediate byte loads to word pairs; duplicate accumulator and repeated word-load cleanup), and optimizer passes repeated until stable.
- Added `docs/plugin.md` covering Maven plugin installation, build flow, goal usage, configuration parameters, and the generated heap-start placement.
- Translator emits the memory manager as the final generated section after code, embedded data, and class-size symbols; when included, its initial heap pointer resolves to the generated image end.
- Added a Java-to-Z80 integration test for `instanceof` with null, direct instances, subclass instances, and unrelated classes.
- README Objects and the heap: 4-byte instance header, bump pointer, Heap.forget rewind (owner first, then children), Heap.top() as a signed 16-bit address, arrays not rewind targets. Also narrowed types, checked exceptions, ROM-resident static byte[], and the JNI frame.
- j2z80.Heap.forget(Object) rewinds ___MEMORY_MANAGER_TOP_POINTER to the instance header (reference minus 4). That instance and everything allocated after it are released. Earlier instances stay. null is a no-op. Arrays are not this header. Heap.top() returns that pointer as a signed 16-bit int. java.lang.Object has no forget().
- Contiguous static byte[] fills in <clinit> (n>=16) become ROM-resident arrays (header+DEFB); the static field points at that payload (no heap copy).
- ZX Spectrum 48 library: border, ink/paper/bright/flash, lower-screen colors, clear, pixel plot/unplot/point, attribute cells, print position, one lower-screen character (Screen.print), frame sync, keyboard matrix, and beeper. Hello-world draws a line-art portrait, an attribute Mandelbrot, a 256-star field released with forget(), then float and double curves. The portrait caption prints Heap.top() as four hex digits.
- Portrait.DATA format: [n,x0,y0,...] where n=0 point, n=1 line, n>1 polyline segment count. Source: iam_line.svg path coords. Regenerate: `python3 tools/export_portrait_from_svg.py`.
- SpotBugs 4.10.4.1 runs on j2z80-plugin during verify (medium and higher). Endemic patterns are listed in src/main/spotbugs/exclude.xml.
- Fixed the embedded Z80 assembler: signed IX/IY displacements, byte immediates in -128..255 (so CP -128 assembles), rejection of LD (SP),n, case-insensitive (BC)/(DE)/(IX)/(IY), forward EQU chains, and DEFM as raw bytes.
- Project version is 2.0.0-SNAPSHOT.
- Added double support. Each Java double is two 16-bit slots holding IEEE binary32. Arithmetic, compare, i2d/l2d/f2d/d2i/d2l/d2f, fields, and double[] are implemented. drem is truncating remainder. multianewarray of double is rejected.
- Added long support. Each Java long is two 16-bit slots holding a signed 32-bit value (low word in the first slot). Arithmetic, shifts, compare, i2l/l2i/l2f/f2l, ldc2_w, fields, and long[] are implemented. multianewarray of long is rejected.
- Added float support. Each Java float is one 16-bit slot holding IEEE 754 binary16. Opcodes: fconst, fload/fstore, faload/fastore, fadd/fsub/fmul/fdiv/frem/fneg, i2f/f2i, fcmpl/fcmpg, freturn, ldc/ldc_w of ConstantFloat, newarray float.
- Fixed translated runtime defects in jvmprocessors *.a80: if_icmpgt equality, jsr/jsr_w return address ($+7), if_icmpne uses JP, baload sign-extends, checkcast null succeeds, idiv/irem by zero pops both saved registers, byte-array type is 1, array size uses RL, free memory is caller SP minus heap top, allocations are zeroed, multi-array skips a zero dimension.
- Fixed stack frame allocation for INVOKESTATIC / INVOKESPECIAL: frame size now uses method maxLocals (bytes = maxLocals * 2), not only argument slots.
- Fixed LabelAndFrameUtils.calculateFrameSizeForMethod: no longer double-counts `this` for instance methods (maxLocals already includes it).
- Fixed bootstrap invoke static detection (INVOKESTATIC, was wrongly INVOKESPECIAL).
- assertLocalVariablesNumber now checks MethodGen.getMaxLocals().
- Test helper registerMockMethod now applies the maxLocals parameter via setMaxLocals.
- Frame size floors at argument slots so native methods (maxLocals=0, no Code attribute) still get a valid frame — unblocks main-jar verify.
- Reworked the JNI guide as docs/jni.md with embedded Java and assembly snippets for a two-argument native void method and a one-argument native int method that reports a checked exception through ___PENDING_EXCEPTION; examples use inline class-level assembly labels.
- Reworked docs/asm.md against the embedded assembler implementation, documenting directives, operand limits, global/local labels, index-register displacement syntax, and examples; ASSERT is diagnostic output rather than a conditional assertion.
- Started Z80Processor JUnit tests in j2z80-plugin: single commands, a DJNZ loop, a two-word CALL return, and the double-argument word order.
- JavaZ80Run compiles a Java class (entry mainz), translates it, runs it on Z80Processor, and reads static int fields. Covered: addition, loops, invokes, tableswitch and lookupswitch, and try/catch/finally (nested, subclass catch, throw from a callee, finally on break).
- TryCatchFinallyTest also covers finally without exceptions: fall-through, return from try, continue/break, nested finally, finally around a callee invoked from several sites, and sequential try/finally blocks.
- Exceptions are checked-only. Unchecked types (RuntimeException/Error and subclasses) are rejected at translate time. A method that declares throws clears/sets ___PENDING_EXCEPTION; call sites check that cell and jump to a covering catch or RET to propagate. Local athrow uses the same compile-time handler match (no global unwind table). Arithmetic/checkcast still JP via ___ATHROW_PROCESSING_CODE_ADDRESS (default 0).
- Record classes translate. java.lang.Record is a bootstrap superclass (constructor only). Compiler equals/hashCode/toString (invokedynamic ObjectMethods) are rewritten before translation. equals is component-wise; a nested record uses that record's equals, other references use identity. hashCode mixes component hashes with 31. toString returns null. A hand-written equals/hashCode/toString without invokedynamic is left as-is.
- Enum constants translate. java.lang.Enum is a bootstrap superclass: the constructor stores the ordinal in the first payload cell and drops the name pointer. Instance fields start at byte offset 2. values() is rewritten to copy $VALUES (array.clone is not translated). valueOf's body returns null; call sites of name() and valueOf are rejected because there is no String. Enum types that extend java.lang.Enum run their static initializers before other classes, and synthetic $SwitchMap classes drop NoSuchFieldError handlers so switch can translate. compareTo and getDeclaringClass stay unsupported.
- Resource exclusion now uses Maven/Plexus SelectorUtils for Ant-style path matching instead of the copied matcher; matching remains case-insensitive and rooted at `/`.
- `j2z80-api` uses Apache Commons IO `IOUtils.readLines` in `Utils.readTextResource`; it retains UTF-8 decoding, LF normalization, final newline behavior, and explicit missing-resource errors.

## 2. Architecture & Technical Discoveries
- COMPACT removes JP/JR only when their target is the next parsed line's label, retaining labels attached to removed jumps and never crossing intervening labels/directives. It changes LD A,0 to XOR A only before a full flag writer; removes CP 0 only before a full flag writer (CP0 -> OR A before branch is excluded because P/V semantics differ); changes LD A,r / NEG to XOR A / SUB r only for B,C,D,E,H,L and no label on NEG; and replaces safe groups of eight ADD HL,HL with LD H,L / LD L,0 (the final doubling group is retained if flags remain live).
- On the ZX Spectrum example, NONE emits 9,755 lines / 192,166 bytes and a 17,204-byte binary; BASIC emits 8,030 lines / 121,899 bytes and a 16,652-byte binary. The sample has no eligible branch-to-next, zero-load/full-flag-writer, CP-zero/full-flag-writer, LD A,r / NEG, or 8-shift groups; it has two runs of five ADD HL,HL that are already size-optimal. It does have two immediate byte-pair loads; combining each into one word load should save two bytes total.
- After repeated word-load optimization, the ZX Spectrum COMPACT output is 8,023 lines / 121,855 assembly bytes and a 16,635-byte binary; duplicate word loads account for a further 15-byte binary reduction.
- AsmOptimizerChain reruns all optimizers until the parsed source is unchanged, allowing deletions from later optimizers to expose earlier peephole opportunities. The five-ADD HL,HL output sequences remain (5-bit shifts); the replacement with LD H,L / LD L,0 only applies to complete 8-shift byte groups.
- COMPACT folds LD A,0 followed by XOR A or OR A into XOR A and removes repeated XOR A / OR A / AND A / LD A,0 operations when the duplicate has no entry label; it retains labels and preserves flag effects.
- COMPACT removes repeated identical LD BC/DE/HL/IX/IY operations in uninterrupted push chains for the same pair. It keeps the first load, pushes a duplicate value as often as needed, and does not remove labeled reloads or cross control-flow entry labels.
- The example POM selects `<optimization>COMPACT</optimization>`.
- Static `byte[] DATA = {…}` is not a class-file blob: javac emits unrolled NEWARRAY+BASTORE in `<clinit>`. StaticByteArrayInitRewriter detects contiguous 0..n-1 fills (n>=16) ending in PUTSTATIC; MethodTranslator emits a ROM-resident array (size byte + length word + payload) and points the static field at the payload — no allocate/LDIR. Writes mutate the image in place.
- ZX Spectrum 48 API is j2z80.spectrum.Screen, Keyboard, and Sound in zx-spectrum-demo-lib, with native bodies in matching .a80 resources. Pixel y=0 is the bottom scanline; attribute row 0 is the top character row. border() matches ROM BORDER: light papers keep black ink in BORDCR. frame() is a short delay with interrupts left disabled; HALT let the ROM keyboard scan treat space as a BASIC key and restart the machine. Before ROM calls, ERR-NR is set to #FF and the new-key flag is cleared. tone() calls ROM BEEPER #03B5 then DI. The first stage draws Portrait.DATA ([n,x0,y0,...]: n=0 point, n=1 line, n>1 polyline) from iam_line.svg path coordinates (Bezier sampled, y flip, centered on 256x192). Regenerate: `python3 tools/export_portrait_from_svg.py`. Keep DATA under ~2.5KB so translate stays under 0xFFFF. The Mandelbrot is 32 by 22 attribute cells in 1/64 fixed point; multiplies stay within +/-170 so the 16-bit product fits. Each cell's color is the paper color, because the bitmap is cleared. The next stage is a StarField: the instance is allocated first, then Star[256] and 256 Star objects (x, y, speed), plotted as pixels that wrap on X. Across and down each use their own 15-bit stir, so the points are not a diagonal. SPACE calls j2z80.Heap.forget on the StarField, rewinding the bump heap over the array and every star. Heap.forget is a bootstrap static call to ___MEMORY_FORGET_OBJECT. After the stars, a float sine and a double Lissajous are plotted. The portrait caption is "press space (top #" plus four hex digits of Heap.top() plus ")". SPACE steps portrait, overview, stars, curves, then repeats. Mandelbrot zoom constants remain for tests.
- Double runtime is DOUBLE_ARITHMETIC_MANAGER.a80. Same two-slot stack order as long: low word on top. Values are binary32, so results match Java float, not full float64.
- Long runtime is LONG_ARITHMETIC_MANAGER.a80. Low word is on top of the stack and in the first local slot; high word is beneath it. Argument area size counts long as two slots. A long return leaves the low word in BC and the high word in DE. Divide by zero throws. Constants outside signed 32-bit are rejected.
- Float runtime is FLOAT_ARITHMETIC_MANAGER.a80, pulled in by NeedsFloatArithmeticManager. Arithmetic is software binary16 (round-to-nearest-even, subnormals, signed zero, inf, NaN). IY points at a 16-byte workspace and is saved/restored. IX is not used.
- f2i clamps to signed 16-bit. Float divide by zero yields infinity and does not throw. frem follows IEEEremainder; a half-precision quotient that overflows becomes NaN.
- tone() must preserve IX around the ROM beeper. The beeper borrows IX, and the invoke epilogue resets the stack from IX, so a borrowed IX jumps into ROM and resets the machine after the greeting.
- ___BEFORE_INVOKE: A = arg area bytes, BC = full frame bytes; lowers SP and sets IX.
- ___AFTER_INVOKE restores previous IX and discards the frame. It keeps BC and DE, because a long or double result returns the low word in BC and the high word in DE. Before the frame is built, each long or double argument has its words exchanged so the low word is the first slot; the arithmetic stack still keeps the low word on top.
- INVOKEVIRTUAL / INVOKEINTERFACE take frame size from VT/IT tables (LabelAndFrameUtils), so they were less affected than static/special.
- Nested loops allocate extra local slots beyond args; undersized frames overwrite caller stack / return addresses.
- Native JNI methods have no Code attribute → BCEL getMaxLocals() is 0; callers must still size the frame from argument count.
- Embedded assembler (z80asm): IX/IY displacement is signed (-128..127). 8-bit immediates accept -128..255 so both CP -128 and CP 255 assemble. EQU is solved by repeating until stable; a cycle throws. DEFM writes one byte per Java char (0..255). Pattern opcodes are copied so callers cannot mutate the table.
- Object layout from NEW: 2-byte cell count, 2-byte class id, then fields. The reference is the first field, so the heap top from before `new` is reference - 4. ___MEMORY_FORGET_OBJECT stores that address back into ___MEMORY_MANAGER_TOP_POINTER. An enum adds one cell for the ordinal only on the class whose superclass is java.lang.Enum. Anonymous constant classes (ACC_ENUM, extending the enum) reuse that cell. Abstract non-enums still have size 0; abstract enums do not, because NEW allocates the constant class.
- JNI resources and their DEFS blocks are emitted before the memory manager; heap starts after the full generated image. This protects image-resident native static data from normal heap growth, but allocations have no stack-top/64K boundary check, and native dynamic allocators are not coordinated.
- Assembler labels run method and field names through normalizeString. `$` in synthetic names (`$VALUES`, `$values`, `$SwitchMap`, `EnumUse$1`) becomes `S`, because `$` is the assembler's location counter. `#` remains the field/method signature separator.
- Maven plugin resource exclusion uses `org.codehaus.plexus.util.SelectorUtils.matchPath`; the Plexus utility is provided by Maven at runtime.
- `Utils.readTextResource` reads classpath resources with Apache Commons IO and normalizes each line to LF, appending a final LF for non-empty content.

## 5. Known Issues & Limitations
- float is half precision, not Java float32. double is binary32, not Java float64. long is 32-bit, not Java's 64-bit long. drem truncates toward zero. Logical long shift is a 32-bit unsigned shift. multianewarray of long or double is not supported.
- IX displacement limits locals to index 0..64 (assertLocalVariablesNumber uses 64).
- Memory allocation is an unchecked bump pointer: exhaustion can collide with the downward-growing stack or wrap the 16-bit address space. Heap.forget also trusts its argument; only a valid ordinary live heap object is safe (not arrays, ROM data, or native-owned references).
- Only documented Z80 instructions in the embedded assembler.
- 16-bit int model: mul/div wrap in 16 bits; shifts are 16-bit (IUSHR does not match a 32-bit Java >>>). No array bounds or null checks on field/array access.
- char is stored as an 8-bit element.
- Only checked exceptions are supported. Unchecked exceptions (RuntimeException, Error, subclasses) cannot be declared, thrown, caught, or subclassed. Runtime faults (e.g. divide by zero) still reset via ATHROW processing address.
- Enum.name and Enum.valueOf are rejected at translate time (no String). compareTo and getDeclaringClass are unsupported. Record toString returns null. Record equals uses identity for reference components that are not themselves records. Lambdas (invokedynamic) inside a method are still unsupported.
- Portrait DATA / static byte[] still count toward the 64K image; compacted byte[] costs ≈ 3 + payload bytes in the program image (field points there; no second heap copy).
- Heap.forget is a stack rewind, not a tracing collector. A forgotten reference is still a bit pattern in a local or field. Arrays use a 3-byte header, so Heap.forget does not rewind to an array. java.lang.Object has no forget().
