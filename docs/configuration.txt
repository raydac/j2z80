Because the translator is a maven plugin, it can be configured.

Goal and artifact
-----------------
Artifact: com.igormaznitsa:j2z80-plugin
Goal: translate (default phase: install)

Parameters
-------------
1. <jarFile>...</jarFile>
Path to the jar which should be translated.
Default: ${project.build.directory}${file.separator}${project.build.finalName}.jar

2. <formats>...</formats>
Set of output formats. Allowed values: A80, BIN, SNA.
Default: A80 only.
 - A80 — assembler source written to ${project.build.directory}/${project.build.finalName}.a80
 - BIN — raw binary written to ${project.build.directory}/${project.build.finalName}.bin
 - SNA — ZX Spectrum 48K snapshot written to ${project.build.directory}/${project.build.finalName}.sna

                   <formats>
                            <format>A80</format>
                            <format>BIN</format>
                            <format>SNA</format>
                   </formats>

3. <startAddress>...</startAddress>
Start address of the translated code (first byte). Default: 28672.
For SNA, the address must be in 0x4000..0xFFFF.

4. <stackTop>...</stackTop>
Stack top for the translated program. Default: 65533.
For SNA, the value must be in 0..0xFFFD.

5. <logAsmText>...</logAsmText>
Boolean. If true, the translated assembler text is logged to the console. Default: false.

6. <excludeResources>...</excludeResources>
Resource patterns to exclude from embedding into the result.

                   <excludeResources>
                            <value>/**/*.xml</value>
                            <value>/**/*.properties</value>
                            <value>/**/*.mf</value>
                   </excludeResources>

7. <optimization>...</optimization>
Optimization level:
 - NONE (default) — no stack-pair cleanup
 - BASIC — removes unnecessary stack command pairs such as PUSH HL / POP HL

Independently of <optimization>, the translator always compacts large static byte[]
initializers in <clinit>. A contiguous fill of 16 or more elements (NEWARRAY byte,
then DUP/index/value/BASTORE for indices 0..n-1, then PUTSTATIC) is replaced by a
ROM-resident array (3-byte header + DEFB payload). The static field points at that
memory; there is no heap copy. Stores into the array write the program image in place
(acceptable on RAM-loaded Z80 targets).

Dependencies
----------------------
The plugin uses project dependencies as libraries when the jar has the z80 classifier.

Example:

    <dependencies>
        <dependency>
            <groupId>com.igormaznitsa</groupId>
            <artifactId>zx-spectrum-demo-lib</artifactId>
            <version>${j2z80.test.version}</version>
            <classifier>z80</classifier>
        </dependency>
    </dependencies>



Example of the plugin configuration
-------------------------------------
    <build>
        <plugins>
            <plugin>
                <groupId>com.igormaznitsa</groupId>
                <artifactId>j2z80-plugin</artifactId>
                <version>2.0.0-SNAPSHOT</version>
                <executions>
                    <execution>
                        <phase>install</phase>
                        <goals>
                            <goal>translate</goal>
                        </goals>
                        <configuration>
                            <formats>
                                <format>A80</format>
                                <format>BIN</format>
                                <format>SNA</format>
                            </formats>
                        </configuration>
                    </execution>
                </executions>
                <configuration>
                    <optimization>BASIC</optimization>
                    <startAddress>28672</startAddress>
                    <stackTop>65533</stackTop>
                    <logAsmText>false</logAsmText>
                    <excludeResources>
                            <value>/**/*.xml</value>
                            <value>/**/*.properties</value>
                            <value>/**/*.mf</value>
                    </excludeResources>
                </configuration>
            </plugin>
        </plugins>
    </build>
