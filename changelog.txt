- 2.0.0 (SNAPSHOT)
    - fixed Z80 assembler index offsets, 8-bit immediates, indirect registers, and forward EQU
    - added float values as 16-bit IEEE binary16, including arithmetic, loads, stores, conversions, and float arrays
    - added long values as signed 32-bit integers in two slots, including arithmetic, shifts, loads, stores, and long arrays
    - added double values as 32-bit IEEE floats in two slots, including arithmetic, comparisons, conversions, and double arrays
    - fixed signed greater-than so equal values do not take the branch
    - fixed jsr and jsr_w so ret continues after the call
    - fixed far not-equal branches, negative byte loads, checkcast of null, and divide-by-zero
    - fixed array sizing, free memory, cleared new objects and arrays, and empty multi-array dimensions
    - fixed stack frame size for method calls so local variables (e.g. nested loops) are reserved
    - added SNA as a target format
    - adaptation for JDK 11 and Maven 3.8+
    - updated dependencies
    - minor fix
    - restructurisation of project
