- 2.0.0 (11-oct-2026)
    - Added Java `float` (binary16), `long` (signed 32-bit), and `double` (binary32) arithmetic, conversions, and arrays.
    - Added checked-exception handling with `try`/`catch`/`finally`; unsupported unchecked exceptions are rejected during translation.
    - Added translation support for records and enums, including enum `switch`.
    - Expanded `ZSystem` with heap rewind and inspection, memory and port I/O, interrupt controls, and CPU halt.
    - Added the `COMPACT` optimizer and ZX Spectrum 48K snapshot output.
    - Embedded large contiguous static `byte[]` initializers in the program image instead of generating heap-fill code.
    - Fixed method frame sizing, wide-value calling conventions, array allocation, and several Z80 instruction translations.
    - Improved the embedded assembler with index displacements, expanded immediate ranges, indirect-register syntax, and forward `EQU` resolution.
